# Origami Fold models

Work from this folder. These are the canonical native `.osf` files; open them in Ori Studio’s **Fold** workspace.

| Folder | Contents |
| --- | --- |
| [completed/](completed/) | 17 completed designs ready for audit. This label does not imply user approval. |
| [in-progress/](in-progress/) | 21 verified partial designs. |
| [excluded/3d/](excluded/3d/) | Box and Crane flat preparations/variants; required 3D completion is excluded. |
| [excluded/cuts/](excluded/cuts/) | 7 partial designs whose tutorials require cuts. |
| [excluded/multi-sheet/](excluded/multi-sheet/) | The 2 Ninja Star modules; assembly is excluded. |
| [archive/](archive/) | Older prototypes, checkpoints, and combined snapshots. Use the current files above for ongoing work. |

The scope is single-sheet flat folding, without required cuts or multi-sheet assembly. Supporting reports, operation logs, and recipes remain in their research folders; their links and the catalog now point here.

[Progress tracker](../../origami-me-flat-catalog/PROGRESS.md) · [Remaining work](../../origami-me-flat-catalog/PROGRESS.md) · [Gap evidence](../../origami-me-flat-catalog/GAPS.md)

The initial 53 native projects were moved without changing their bytes. Whale has since been completed, with its original seven-node prefix retained in `archive/checkpoints/whale-before-rabbit-ear.osf` (subsequent checkpoints are also retained). Your Heart and Cicada edits are preserved. Cicada’s original completed path is ready for audit, but its five added user branch steps have not received a source/visual audit. Dove is complete through source 16 / Fold 17 using direct nested reverses and a two-pair crimp; its earlier prefixes and CP control remain archived. Squirrel uses a direct crimp at source 16 / Fold 19. Both prior versions are retained in archive/checkpoints/. New diagram authoring is paused while implementation priorities are addressed.

## Saving and continuing

Save edits directly to these files. Campaign generators retain their saved-file hash checks and refuse to overwrite user edits. New attempts default to `in-progress/`; when a design is completed, move it to `completed/` and update its catalog/validation paths. Folder placement alone never marks a design audited.

The archive contains historical alternatives, including some incorrect or incomplete attempts. Its combined snapshot predates current user edits and is not the working copy of those designs.
